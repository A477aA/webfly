# webfly — браузерный симулятор воздушного боя

**Русский** · [English](README.en.md)

**[▶ Играть онлайн](https://a477aa.github.io/webfly/)** · [зеркало на своём сервере](http://193.233.216.107/)

Аркадный 3D-авиасимулятор на **Су-27 «Фланкер»**: динамика полёта, догфайт с ИИ,
пять типов управляемых ракет, бомбометание с баллистическим прицелом, наземные цели
и ПВО. Написан на чистом JavaScript и [three.js](https://threejs.org/) — без сборки,
фреймворков и внешних ассетов: все текстуры, звуки и модели генерируются кодом.

---

## Возможности

**Полёт.** Форс-модель твёрдого тела: тяга, подъёмная сила по коэффициенту `CL(α)`,
лобовое и индуктивное сопротивление, гравитация, флюгерная устойчивость, срыв на
критическом угле атаки. Крен рождает разворот, свечка вверх честно теряет скорость,
закрылки улучшают несущие свойства ценой сопротивления.

**Управление.** Два режима — «Простое» (курсор доводит нос, автоматика кренит в вираж,
выравнивает крылья и страхует от сваливания) и «Продвинутое» (мышь работает как ручка
управления, помощи нет). Клавиатура имеет приоритет и всегда даёт полный контроль.

**Вооружение.** Пушка ГШ-30-1 с реальной баллистикой (860 м/с), установленная в правом
наплыве крыла со сведением стволов, упреждающим прицелом и сектором доводки. Пять типов
ракет со своими головками самонаведения: Р-73 (ИК), Р-27 (полуактивная РЛ), Р-77
(активная РЛ), Х-31П (противорадиолокационная), Х-29 (воздух-земля). Свободнопадающие
бомбы с прицелом, показывающим реальную точку падения. Тепловые ловушки.

**Нашлемная система целеуказания.** Курсор — это взгляд лётчика: захват идёт по нему,
поэтому ракеты можно пускать под углом к оси самолёта, как позволяет «Щель-3УМ».

**Противник.** Истребители с четырьмя манерами ведения боя (агрессор, энергетик,
манёвренный, снайпер), тяжёлые бомбардировщики, наземные ЗАК и вражеский ас. ИИ держит
дистанцию боя, расходится на сближении и идёт на таран только при смертельных
повреждениях. Рядом дерутся союзники.

**Мир.** Процедурный рельеф, шейдерная вода с волнами и бликом, объёмные облака,
атмосферное небо, тени и отражения. Точки интереса: вражеская авиабаза и корабельная
группа с авианосцем.

**Интерфейс.** Лента компаса, радар с тремя дальностями, выбор цели, метки противников
и союзников, предупреждение о пуске ракеты, приборная панель с живой телеметрией в виде
из кабины. Локализация RU/EN.

## Управление

| Клавиши | Действие |
|---|---|
| **Мышь** | манёвр и наведение · **ЛКМ** пушка · **ПКМ** ракета |
| `W` `S` / `A` `D` / `Q` `E` | тангаж / крен / рыскание (или `Z` `C`) |
| `Shift` `Ctrl` | тяга |
| `1`…`5` · `F` | выбор и пуск ракеты |
| `B` · `X` | режим бомбометания · тепловые ловушки |
| `T` · `Y` · `N` | выбор цели · смотреть на цель · дальность радара |
| `G` · `H` | закрылки · ремонтный комплект |
| `V` · `O` | камера (облёт / кабина / дальний) · взгляд назад |
| `Esc` · `R` · `U` | пауза · рестарт · режим разработчика |

## Запуск локально

```bash
git clone https://github.com/A477aA/webfly.git
cd webfly
```

Дальше просто откройте `index.html` в браузере — модули подключены классическими
`<script>` и работают из `file://`. Либо поднимите статический сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

### Настройка

Все настраиваемые величины собраны в **`js/data.js`** — правьте только его:

| Раздел | Что задаёт |
|---|---|
| `DATA_FLIGHT` | тяга, подъёмная, сопротивление, эффективность рулей |
| `DATA_FLAPS` | эффект закрылков и автоматика выпуска |
| `DATA_CONTROL` | ощущение управления: чувствительность, доводка, страховки |
| `DATA_GUNS` / `DATA_MISSILES` | вооружение: дальность, скорость, урон, тип ГСН |
| `DATA_UNITS` | прочность и скорость всех машин |
| `DATA_PILOT_STYLES` | манеры ведения боя противников |
| `DATA_AI` | дистанции боя, таран, подкрепления, появление аса |
| `DATA_DIFFICULTY` | сложность: темп огня, точность, численность |
| `DATA_WORLD` | размер карты, границы зоны, расположение целей |

## Физическая модель

Самолёт моделируется как твёрдое тело: положение и скорость в мировых координатах,
ориентация кватернионом, угловая скорость в связанных осях.

**Силы:**

```
Тяга          T = maxThrust · throttle      по вектору носа
Подъёмная     L = min(g, k·q) + k·q·CL(α)   перпендикулярно вектору скорости
Сопротивление D = q · (Cd0 + K·CL²)         против вектора скорости
Гравитация    G = −g                        вниз
```

где `q = V²` — скоростной напор, `CL(α) = clAlpha · α`. Балансировочная составляющая
подъёмной ограничена весом — иначе на большой скорости самолёт «выбрасывает» вверх.
Манёвренная составляющая ограничена предельной перегрузкой.

За критическим углом атаки подъёмная падает — наступает срыв. Закрылки поднимают
критический угол и увеличивают несущие свойства, добавляя сопротивление.

**Моменты** по каналам тангаж/крен/рыскание пропорциональны отклонению рулей и
эффективности, зависящей от скоростного напора, с угловым демпфированием. Флюгерная
устойчивость доворачивает нос к вектору скорости.

**Соглашение осей:** нос — локальный `−Z`, верх — `+Y`, правое крыло — `+X`.

**Расчётные характеристики:** максимальная скорость 780 км/ч, крейсерская 650 км/ч,
скорость сваливания 125 км/ч, тяговооружённость 0.85, вираж до 8G без срыва.

## Технические детали

- **Ноль внешних ассетов.** Текстуры рисуются на canvas, звук синтезируется через
  WebAudio, модели собираются из примитивов кодом.
- **Освобождение ресурсов.** Каждая удалённая пуля, ракета и частица корректно
  освобождает геометрию и материалы — без этого видеопамять утекает.
- **Независимость от частоты кадров.** Физика полёта и баллистика бомб интегрируются
  фиксированным шагом, поэтому поведение одинаково на 30 и 144 FPS.
- **Переиспользование ресурсов.** Общие геометрии и материалы для трассеров и обломков,
  кэш DOM-элементов, буферы векторов вместо аллокаций в кадре.
